Instruções para correção manual

Se preferir corrigir manualmente as imagens no site principal:

  1. Localize os slides de produtos no HTML do site
  2. Para cada produto, copie o HTML correspondente desta página
  3. Substitua o conteúdo do elemento .product-images .swiper-wrapper pelo HTML da imagem

Exemplo de HTML para inserir:

<div class="swiper-slide">
  <img src="https://varandamix.com/wp-content/uploads/2024/01/sofa-organico-700x700.webp" 
       alt="Sofá Orgânico Napoli" style="width: 100%; height: auto;">
</div>
